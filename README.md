# Entra ID IAM Lab Series

This repository serves as the central hub for the Entra ID IAM Lab Series — a collection of hands-on identity and access management labs built around Microsoft Entra ID. Each lab builds on the previous one, starting with foundational tenant configuration and progressively covering user/group RBAC, authentication security and MFA, Conditional Access, Privileged Identity Management, enterprise SSO, and access governance. All labs are performed in a live Microsoft Entra ID tenant and reflect real-world IAM practices aligned with the responsibilities of an entry-level IAM Analyst. The series is designed to build a comprehensive Entra ID portfolio demonstrating hands-on proficiency across core competencies commonly required in IAM Analyst job descriptions.

---

## Prerequisites

The following are required before starting the Entra ID IAM Lab Series:

- **Microsoft Entra ID Tenant** — Sign up for a free Entra ID tenant at [entra.microsoft.com](https://entra.microsoft.com). This tenant will be used across all labs in the series and should not be deleted between labs.
- **Microsoft Entra ID P1 or P2 License** — Required for several labs in this series (branding, Conditional Access, PIM, access reviews). A free 30-day trial is available under Billing → Licenses → Try/Buy.
- **GitHub Account** — Required to follow along with lab documentation and host your own portfolio.
